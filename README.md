## Проект "E-commerce - электронная торговля"

+ Описание основных сущностей и инициализация объектов 

## Используются следующие зависимости:

- poetry init
- json
- pytest
- pytest-cov
- pathlib
- datetime
- poetry add --group lint flake8 black mypy isort 



## Использование:
+ Создан класс Product в модуле product, для класса описаны необходимые атрибуты  
+ Создан класс Category в модуле category, для класса описаны необходимые атрибуты
+ Для класса Category добавлены два атрибута класса category_count и product_count
+ Добавлен модуль utils, в котором реализована функция для чтения json-файлов и функция для получения объектов класса
+ Программа запускается через if __name__ == "__main__": в модуле main
    

## Проверка группой линтеров:
* При запуске линтера Flake8 обнаружено 1 ошибку про длинные строчки.
* При проверке линтером mypy выводится много ошибок.
* Isort поправил в коде импорты.

## Тестирование
При тестировании инициализации классов и модуля utils тестами покрыто 92 % кода. Все тесты завершаются ожидаемым образом
