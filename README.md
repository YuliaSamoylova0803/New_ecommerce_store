## Проект "E-commerce - электронная торговля"

+ Описание основных сущностей и инициализация объектов 

## Используются следующие зависимости:

- poetry init
- json
- pytest
- pytest-cov
- pathlib
- datetime
- poetry add --group lint flake8 black mypy isort 



## Использование:
+ Создан класс Product в модуле product, для класса описаны необходимые атрибуты, дописаны режимы доступа и методы класса  
+ Создан класс Category в модуле category, для класса описаны необходимые атрибуты, дописаны режимы доступа и методы класса  
+ Для класса Category добавлены два атрибута класса category_count и product_count
+ Написан новый класс CategoryIterator на основе класса Category
+ Добавлен модуль utils, в котором реализована функция для чтения json-файлов и функция для получения объектов класса
+ Реализованы два класса наследника от Product: класс Smaptphone и Lawngrass
+ В наследуемых классах добавлен магический метод add, repr, str 
+ Добавлено два абстрактных класса и определены наследники
+ Написана миксина для класса Product
+ Программа запускается через if __name__ == "__main__": в модуле main
    

## Проверка группой линтеров:

* При проверке линтером mypy выводится много ошибок.
